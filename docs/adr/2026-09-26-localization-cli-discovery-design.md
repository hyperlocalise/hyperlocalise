## Contracts

Provider file commands, flat-JSON TMS entry sync, Platform file sync, and local translation are different workflows. Platform takes precedence when both sync configuration blocks exist. Platform provider capabilities and file views vary; CLI format support does not imply Platform support. Preserve these distinctions in every hub.
