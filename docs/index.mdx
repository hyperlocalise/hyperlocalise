## How the pieces fit together

A workspace contains your team, projects, connections, and shared language resources. A project holds source files and language settings. Translation jobs generate content; the Content Editor lets your team review it. Downloads and sync move the result to its destination.

Uploading a source file does not by itself request a translation. Set up a [source-upload automation](/platform/automation/create-automation) when you want those steps connected.
