Hyperlocalise is infrastructure for multilingual content operations.

Use Cloud to take work from intake through generation, review, and release. Connect the CLI or API when source files already live in git or a pipeline.

## Choose a path

Both paths use the same Cloud project. Content operations stay in one place. Git stays the source of truth when you want it.

## Cloud surfaces

These are parts of the same operations layer, not separate products.

1. [Content Editor](/platform/cat) — review multilingual content in context
2. [Automations](/platform/automations) — playbooks on schedule, GitHub, or upload
3. [Knowledge](/platform/knowledge) — guideline, glossaries, and translation memory

Connect GitHub, a TMS, or keys from [Integrations](/platform/integrations) and [Settings](/platform/settings).

Local generation, eval, and TMS adapters live in the [CLI docs](/cli).
