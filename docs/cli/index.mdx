The Hyperlocalise CLI translates files in your repository using your chosen AI
provider. Preview the work, generate translations, and review the changes before
releasing. Connect to Cloud or a TMS when you need a shared review workflow.

## The everyday workflow

1. Map source files to target paths in `i18n.yml`.
2. Preview the translation plan with `hyperlocalise run --dry-run`.
3. Generate translations with `hyperlocalise run`.
4. Review the diff and run `hyperlocalise check`.
5. Commit the translated files and `.hyperlocalise.lock.json`.

The lockfile records translation progress so later runs can skip completed work.
See [local translation](/cli/workflows/local-generation) for the full workflow.
