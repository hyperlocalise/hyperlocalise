After the [quickstart](/cli/getting-started/quickstart), your project contains:

```text
locales/
    en-US.json                 # Source messages
    es-ES.json                 # Generated Spanish translations
i18n.yml                       # Locales, paths, and provider settings
.hyperlocalise.lock.json        # Translation progress
.env.local                     # Local credentials; do not commit
```

## What to commit

Keep your source files, reviewed translations, `i18n.yml`, and lockfile in version
control. Keep API keys in your local environment or CI secrets.

The [lockfile](/cli/reference/lockfile-contract) lets subsequent runs reuse
completed work. Review its changes alongside the generated files.

## Add more files or locales

Add a locale under `locales.targets` to generate another language. Add mappings
under a bucket's `files` list to translate more files. Use separate buckets for
content with different paths or settings.

When you omit `groups`, the CLI runs every configured bucket for every target
locale. You can keep the initial configuration small and introduce groups later.

Use [path templates](/cli/configuration/path-templates) for shared layouts and the
[file format guides](/cli/reference/formats/overview) for format-specific examples.
