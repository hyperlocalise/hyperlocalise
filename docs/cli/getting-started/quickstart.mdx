This guide uses OpenAI and one JSON file. You need the [CLI installed](/cli/getting-started/install)
and an OpenAI API key. For another setup, choose an [AI provider](/cli/providers/overview)
or a [file format](/cli/reference/formats/overview).

## 1. Create a source file

From your project directory, create `locales/en-US.json`:

```json
{
    "welcome": "Welcome",
    "greeting": "Hello, {name}!"
}
```

## 2. Configure the project

Create `i18n.yml` in the project root:

```yaml
locales:
    source: en-US
    targets:
        - es-ES

buckets:
    app:
        files:
            - from: locales/{{source}}.json
              to: locales/{{target}}.json

llm:
    profiles:
        default:
            provider: openai
            model: gpt-5.2
```

A bucket groups related source-to-target file mappings. This one reads
`locales/en-US.json` and writes `locales/es-ES.json`.

For an existing project, you can also use [`hyperlocalise init`](/cli/commands/init)
to scaffold a configuration, then adjust its file paths and provider.

## 3. Add your API key

Add the key to `.env.local` in the project root:

```dotenv
OPENAI_API_KEY=your-openai-api-key
```

Keep this file out of version control. The CLI reads `.env` and `.env.local`
automatically; exported shell variables take precedence. See
[provider credentials](/cli/configuration/provider-credentials) for other providers.

## 4. Preview and translate

Preview the work:

```bash
hyperlocalise run --dry-run
```

Check that the plan includes your source file and Spanish target. Then generate:

```bash
hyperlocalise run
```

The CLI creates `locales/es-ES.json` and records progress in
`.hyperlocalise.lock.json`. Translated wording can vary by model; the keys and
`{name}` placeholder should remain intact.

## 5. Review the result

Open the generated file and review the diff. Check translation integrity and
inspect progress:

```bash
hyperlocalise check
hyperlocalise status --output csv
```

Commit the source, configuration, translated file, and lockfile after review.
When source messages change, repeat the preview and translation commands.
