Run commands from the directory containing `i18n.yml`:

```bash
hyperlocalise [command]
```

New to the CLI? Start with the [quickstart](/cli/getting-started/quickstart).
The reference below groups commands by task.

## Common tasks

| Task | Command |
| --- | --- |
| Create a configuration | [`init`](/cli/commands/init) |
| Preview or generate translations | [`run`](/cli/commands/run) |
| Extract React Intl messages | [`extract`](/cli/commands/extract) |
| Prepare translation JSON | [`pack`](/cli/commands/pack) |
| Validate translation integrity | [`check`](/cli/commands/check) |
| Report translation progress | [`status`](/cli/commands/status) |
| Compare translation quality | [`eval`](/cli/commands/eval) |
| Upload local changes | [`sync push`](/cli/commands/sync-push) |
| Download remote translations | [`sync pull`](/cli/commands/sync-pull) |

Provider-specific file operations live under `crowdin`, `phrase`, `smartling`, and
`lokalise`. Check the relevant integration before choosing between those commands
and entry-based `sync`. Use the sections below for flags and examples.
