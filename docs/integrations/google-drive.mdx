# Google Drive

Connect Google Drive, choose folders on the Integrations page, and use a workspace automation to import supported files into a Hyperlocalise project. Translations are written back under per-locale subfolders as `[locale] Filename.ext`.

## Connect Google Drive

1. Open workspace **Integrations → Guidelines** and find **Google Drive**, then choose **Connect**.
2. Sign in with Google and approve access when prompted. Hyperlocalise reads files in folders you select and writes translated copies under locale subfolders in those folders.
3. After connecting, use **Add folders** to select **My Drive** or **Shared drive** folders. You can add or remove folders anytime.
4. Reconnect if Integrations shows that authorization expired or needs to be renewed.

## Create the automation

1. Open workspace **Automations** and create or edit an automation with the **Translate Google Drive files** skill (or apply the **Translate Google Drive files** template).
2. Attach a native project and set source and target locales under [project Settings → Locales](/platform/projects/languages).
3. Select the connected Google Drive folders to import from.
4. Use a **manual** trigger or **schedule** for import. Import does not push translations to Drive.
5. After translation, use **Push to Google Drive** from the Content editor (or your orchestrator flow) to write locale files back.

Google Drive is not a trigger type. Use **Run now** or a schedule for import; push is a separate action.

## Supported files

| Source | Ingest format |
| --- | --- |
| Google Docs | DOCX |
| Google Sheets | XLSX |
| Google Slides | PPTX |
| PDF | Markdown (text extraction via unpdf) |
| Other supported project formats | Original extension (JSON, CSV, HTML, MD, DOCX, etc.) |

## Write-back

For each target locale (defaults to the project’s target locales), Hyperlocalise creates or updates:

`ParentFolder/{locale}/[{locale}] OriginalName.ext`

Google Docs, Sheets, and Slides are uploaded back as native Google file types when the source was a Google app file.

## Known limitations

- If Google Drive auto-converts an upload to a Google Doc, export returns DOCX and the original format (for example `.md`) cannot be recovered.
- Google Apps Script, Drawings, Forms, and Sites are not translated.
- Image, video, and audio files are skipped.
- ZIP and other archive files are skipped.
- PDF translations are Markdown text only; layout is not preserved.

## Limits

- **5,000** files shown in the Integrations folder browser (per folder listing).
- **10** nested folder levels when walking connected folders.
- **100 MB** maximum file size per file.
