---
title: "Connect design tools"
description: "Use Canva connections and Figma personal tokens for design translation workflows."
---

Design tools use a personal access token to work with Platform files and translation jobs. Your token inherits your workspace role and project access; selecting scopes does not grant permissions your account lacks.

## Canva

1. Create a [personal access token](/platform/settings#personal-access-tokens) with `files:read`, `files:write`, `jobs:read`, and `jobs:write`.
2. Open **Integrations** → **Canva** and create a connection.
3. Select the token and a native project. The connection uses that project's source language and target languages. Do not set a separate Canva locale list.
4. Copy the connection token shown once after creation, or skip this step and connect with OAuth from the Canva app.
5. In the Hyperlocalise Canva app, connect with OAuth or paste the connection token. Select pages, then collect one page or every selected page. Each page becomes `canva/designs/<design-slug>/page-<n>.json`. Generate each project language, then Add to design.

Languages appear as **English (en-US)**. Jobs still use the project tags. Add to design replaces text on the Canva page you pick, or replaces every matching collected page. It does not insert a page. Change languages in [project settings](/platform/projects/languages), not in Canva. Inspect layout after applying another language, especially for longer text.

## Figma

If your team has access to the Hyperlocalise Figma plugin, create a personal token with `files:read` and `jobs:read`. Add `files:write` and `jobs:write` to create translation work.

Enter the token in the plugin, select a native project, and use its extraction, job creation, generation, and pull workflow. Review the result on the target page after completion.

Plugin installation depends on how it is distributed to your team. If you do not have the plugin, [contact support](/platform/help/contact-support) for availability and installation guidance.

## Resolve access or job failures

Check the selected workspace/project, token scopes, account role, and job status. If you lost a one-time secret, replace it rather than expecting to reveal it again. Revoke old credentials when replacing a connection. See [Connection troubleshooting](/platform/help/connections).
