---
title: "Connect Bitbucket"
description: "Connect Bitbucket Cloud once for your workspace to sync repository files with your projects."
---

Connect Bitbucket Cloud to pull a repository's source files into a project and send approved translations back as a pull request. An admin connects Bitbucket once for the whole workspace; every project sync then uses that connection, including syncs that run on a schedule.

## Connect Bitbucket

1. Open workspace **Integrations**, find **Bitbucket**, and select **Connect**.
2. Sign in to Bitbucket in the window that opens and approve access.
3. The window closes and the row shows **Connected for the whole workspace**.

Every project sync in the workspace reaches the repositories the connected Bitbucket account can see, and anyone who can change a project's settings can sync any of them. Connect with an account that belongs only to the repositories you want to sync, with permission to write to them and open pull requests. With read access only, syncs pull files and each run says why translations weren't sent.

## Sync a repository

Open the project's **Settings**, select **Sync**, choose **Bitbucket** as the repository service and pick the repository. Turn on **Sync on push** to run the sync whenever its branch is pushed to; that needs admin access to the repository for the connected account. A visual workflow **Content sync** step can sync a Bitbucket repository too. The rest works the same as a GitLab sync: see [Sync content with a repository](/platform/automation/content-sync#pull-from-bitbucket).

## Reconnect or disconnect

If the admin who connected Bitbucket leaves the workspace, or Bitbucket asks to approve access again, the row says Bitbucket needs to be connected again and project syncs stop until an admin selects **Connect** again.

**Disconnect** removes the connection for the whole workspace. Project syncs keep their settings and start working again once Bitbucket is connected.

If a repository is missing from a project's Sync settings, check that the connected Bitbucket account can see it. See [Connection troubleshooting](/platform/help/connections).
