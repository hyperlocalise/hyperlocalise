---
title: "2026 June"
description: "Hyperlocalise Platform changes in June 2026."
---

1. **Content Editor workspace.** Review source and target text, glossary and translation-memory suggestions, and AI recommendations in one editor. Generation and approval stay separate steps. See [Review translations](/platform/cat) and [Your first translation](/platform/getting-started).
2. **Crowdin, Phrase, and Lokalise connections.** Connect a supported TMS from **Integrations**, then open the provider's project in Platform. Capability boundaries differ by provider. See [TMS integrations](/platform/tms), [Connect your tools](/platform/integrations), and [Moving to Hyperlocalise](/platform/getting-started/moving-to-hyperlocalise).
3. **Teams.** Create teams, assign members, and use teams to grant project access. See [Invite teammates](/platform/workspace/members) and [Project access](/platform/projects/access).
4. **Billing and plan usage.** **Settings** → **Billing** shows plan usage, invoices, and plan changes. Only administrators can open the billing portal. See [Manage billing and usage](/platform/workspace/billing).
5. **Workspace knowledge.** Upload shared style and product context so automations and reviewers use the same instructions. See [Language resources](/platform/knowledge) and [Add translation guidelines](/platform/knowledge/guidelines).
6. **Canva design translation.** Upload design text, run a file translation job, and apply completed locales in the Hyperlocalise Canva app. Inspect layout after switching language. See [Connect design tools](/platform/connections/design-tools).
7. **GitHub repository context for automations.** After you connect GitHub and enable repositories, automations can use repository context. Refreshing the repo list does not upload sources. See [Connect GitHub](/platform/connections/github) and [Automate your work](/platform/automations).
8. **Glossary compliance.** The Content Editor warns on missing required terms and forbidden alternatives. Mark forbidden terms when you create glossary concepts. See [Language resources](/platform/knowledge) and [Improve translation quality](/platform/help/quality).
9. **Queue filters and share links.** Filter the queue and copy a link to a segment. See [Review translations](/platform/cat).
10. **Per-file translation import.** Import an existing target file against one native source path. Matching keys are marked approved. See [Import existing translations](/platform/translation/import).
11. **Native comments.** Add comments on native project strings in the Content Editor. Crowdin issue comments also appear for connected Crowdin projects. See [Review translations](/platform/cat).
12. **Job views.** Switch project jobs between row and kanban layouts. **My Jobs** splits work you created from work assigned to you. See [Track and recover jobs](/platform/translation/jobs).
13. **Contentful webhook trigger.** Saved automations can start from a Contentful entry create or update event. A webhook trigger does not by itself sync Contentful files. See [Create a translation automation](/platform/automation/create-automation).
14. **Trust Center.** Security and compliance documents are available from the Trust Center linked in the docs footer. See [Contact support](/platform/help/contact-support) if you need a specific control mapped to a workflow.
15. **Translate-on-upload for native projects.** Uploading a source file can start a matching automation when you configure a **Source upload** trigger. Uploading alone still does not translate. See [Upload source files](/platform/projects/files) and [Create a translation automation](/platform/automation/create-automation).
16. **Lokalise and Phrase OAuth.** Complete the provider authorization flow, then verify the intended account and project before you review strings. See [TMS integrations](/platform/tms) and [Connection troubleshooting](/platform/help/connections).
17. **Native project workflow.** Native projects store source files and translations in Platform: create the project, upload files, request translation, review, and download. See [Create a project](/platform/projects/create-project), [Translation workflows](/platform/translation/workflows), and [Getting started for managers](/platform/getting-started/managers).
