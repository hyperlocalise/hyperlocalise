---
title: "2026 July"
description: "Hyperlocalise Platform changes in July 2026."
---

1. **All-files Content Editor.** Open **Content Editor** in the project sidebar to review every file in one queue instead of one file at a time. Filter and search still apply. See [Review translations](/platform/cat).
2. **Side-by-side review.** The editor shows source and target together, with save draft and approve on the current string. Share a segment link when a teammate needs that row. See [Review translations](/platform/cat) and [Roles and permissions](/platform/workspace/roles).
3. **Native and provider jobs.** Create, inspect, and delete translation jobs for native projects and connected Crowdin, Lokalise, or Phrase projects. Use **Open in provider** when the connected system owns the job. See [Track and recover jobs](/platform/translation/jobs) and [TMS integrations](/platform/tms).
4. **Crowdin, Lokalise, and Phrase in the Content Editor.** Connected projects browse provider files and write supported saves back to the provider. Smartling connections do not currently expose a Content Editor. See [TMS integrations](/platform/tms) and [Moving to Hyperlocalise](/platform/getting-started/moving-to-hyperlocalise).
5. **Public files and jobs API.** Upload sources, create jobs, poll status, and download reconstructed translations at `https://hyperlocalise.com/api/v1` with an organization API key. The CLI uses the same API for [Platform sync](/platform/cli). See [Files and jobs](/platform/api) and [Choose an API](/platform/developers/api-overview).
6. **MCP Server tool in automations.** Connect an external MCP server from **Integrations**, then add the **MCP Server** tool to an automation. To connect an agent *to* Platform, use the [hosted MCP server](/platform/mcp) instead. See [Connect your tools](/platform/integrations).
7. **Knowledge Memory.** Workspace and project **Guideline** pages store instructions that automations and the Content Editor can use. Updating a guideline does not rewrite existing translations. See [Language resources](/platform/knowledge) and [Add translation guidelines](/platform/knowledge/guidelines).
8. **Teams and member assignment.** Invite people from **Members**, choose a role, and add them to a team for project access. A workspace role without team access still cannot open a private project. See [Invite teammates](/platform/workspace/members), [Roles and permissions](/platform/workspace/roles), and [Project access](/platform/projects/access).
9. **File tree search and actions.** Search the project file tree and use context-menu actions to open, import, or download a path. Keep source paths stable across uploads. See [Upload source files](/platform/projects/files) and [Update source content safely](/platform/guides/update-source-content).
10. **Import and download on Files.** Restore **Import translations** and **Download translations** on the files page. Import writes approved targets for matching keys; download returns complete target files. See [Import existing translations](/platform/translation/import) and [Download translated files](/platform/translation/download).
11. **New Request in the chat dock.** One-off agent requests open as a dedicated conversation. Identify the project, files, and locales before confirming. See [Start a translation](/platform/translation/start).
12. **App language.** The workspace UI follows the language you select in the app shell. Product UI locale is separate from project source and target locales. See [Workspace administration](/platform/settings).
13. **Board comments and permanent URLs.** Issues support threaded comments with @mentions and stable URLs you can share. See [Resolve translation issues](/platform/translation/issues).
14. **Ahrefs and Semrush in automations.** Connect those accounts from **Integrations**, then add the matching tool to a saved automation. See [Connect your tools](/platform/integrations).
15. **Translate with agent.** Native project files expose **Translate with agent** so a scoped request can enqueue generation without leaving Files. Review the job, then open the Content Editor. See [Start a translation](/platform/translation/start) and [Your first translation](/platform/getting-started).
16. **TMS source upload through the public API.** The files API can send sources into a connected TMS project when that provider supports the path. See [Files and jobs](/platform/api) and [TMS integrations](/platform/tms).
17. **Chat dock repository context.** Select a GitHub repository so the agent can look up source usage while you review a string. Connecting GitHub still does not move files until you configure sync or an automation. See [Connect GitHub](/platform/connections/github) and [Review translations](/platform/cat).
18. **CSV import for Board.** Import tracker rows with a column-mapping wizard when you already have an issue list. See [Resolve translation issues](/platform/translation/issues).
