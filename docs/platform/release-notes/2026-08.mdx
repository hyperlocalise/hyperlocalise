title: "2026 August"
description: "Hyperlocalise Platform changes in August 2026."
---

1. **Personal access tokens.** Every active member can create a token that acts as that person in the workspace. Tokens inherit the owner's role and project access. Use them for the [Figma plugin](/platform/connections/design-tools), [Canva connections](/platform/integrations#canva), and local scripts. Coding agents still authenticate through [MCP OAuth](/platform/mcp), not PATs. See [Personal access tokens](/platform/settings#personal-access-tokens).
2. **Figma plugin.** Extract text from a Figma page, create translation jobs, and pull completed locales with a personal token. Review layout on the target page after apply. See [Connect design tools](/platform/connections/design-tools).
3. **Markdown and MDX as documents.** `.md` and `.mdx` files open as editable documents rather than key-value queues. See [Supported formats](/platform/file-formats).
4. **Standards-compliant TMX import and export.** Native translation memories import and export TMX 1.4 with validation reports. CSV remains available for spreadsheets. See [Translation memory import and export](/platform/translation-memory-import-export).
5. **Translation-memory explorer.** Search, filter, and paginate TM entries. Open an entry to inspect provenance and edit it when you have access. See [Language resources](/platform/knowledge).
6. **Concept-based glossaries.** Native glossaries store concept-linked source and target terms, including forbidden terms. Workspace, team, and project linking control who can edit. Provider glossaries stay read-only. See [Language resources](/platform/knowledge) and [Glossary import and export](/platform/glossary-import-export).
7. **Segment locks.** Lock a string in the Content Editor so a grouped save or automation does not overwrite it. Locked copies stay out of merge-string writes. See [Review translations](/platform/cat) and [Merge strings](/platform/translation/merge-strings).
8. **Maximum length on strings.** Set or import a character limit on native strings. The editor reports **Length** failures before approval. See [Review translations](/platform/cat) and [Improve translation quality](/platform/help/quality).
9. **Queue filters, sort, and filtered download.** Filter the queue by untranslated, needs review, approved, has issues, skipped, hidden, and unsaved translations. Sort untranslated first. Export the filtered view as CSV, TMX, XLIFF, or XLSX, up to 5,000 matching segments. See [Review translations](/platform/cat), [Download translated files](/platform/translation/download), and [Prepare a review handoff](/platform/guides/review-handoff).
10. **Hidden strings.** Hide strings from the default queue on native projects and supported Crowdin workflows. Bulk hide is available where the provider supports it. See [Review translations](/platform/cat).
11. **Subtitles.** Native projects accept `.srt` and `.vtt` files for file translation jobs and segment review. See [Supported formats](/platform/file-formats), [SRT](/cli/reference/formats/srt), and [WebVTT](/cli/reference/formats/webvtt).
12. **Image, video, and Office File views.** File view covers `.png`, `.jpg`, `.webp`, `.mp4`, `.docx`, `.xlsx`, and `.pptx`. Automatic file translation jobs do not cover Office files; upload or edit the translated file in File view. See [Supported formats](/platform/file-formats) and [Upload source files](/platform/projects/files).
13. **Source-upload automations from existing files.** A **Source upload** trigger can run against files already in the project, not only a new upload event. Test with a small file first. See [Create a translation automation](/platform/automation/create-automation) and [Update source content safely](/platform/guides/update-source-content).
14. **Human-readable Board IDs.** New issues use the project identifier as a prefix, such as `HL-12`. Change the identifier in [project settings](/platform/projects/settings); existing IDs keep their original prefix. See [Resolve translation issues](/platform/translation/issues).
15. **Issue inbox.** Workspace **Inbox** collects issue notifications. Open an item to the matching Board entry. See [Resolve translation issues](/platform/translation/issues) and [Contact support](/platform/help/contact-support).
16. **Create-job composer.** Native and provider projects share one create-job flow. Provider-backed jobs can still open in the connected TMS. See [Track and recover jobs](/platform/translation/jobs), [Start a translation](/platform/translation/start), and [TMS integrations](/platform/tms).
17. **Per-project guidelines.** Upload tone, audience, and product context on the project or the workspace. Supported files include Markdown, PDF, DOCX, PPTX, CSV, JSON, and TXT. See [Add translation guidelines](/platform/knowledge/guidelines).
18. **MCP Board tools.** Hosted MCP can list, create, and update Board items and comments (`list_issues`, `create_issue`, `get_issue`, `update_issue`, `list_issue_comments`). See [MCP tool reference](/platform/developers/mcp-tools).
19. **Translate-on-source-upload template.** Saved automations include a template that translates uploaded source content into the project's target locales and leaves output for review. See [Create a translation automation](/platform/automation/create-automation) and [Automate your work](/platform/automations).
20. **GitHub automation triggers.** GitHub push and pull-request-opened events can start a saved automation after you [connect GitHub](/platform/connections/github) and enable the repository. See [Create a translation automation](/platform/automation/create-automation) and [Fix automation problems](/platform/help/automations).
21. **Default translation memory for native projects.** New native projects receive a workspace translation memory so the Content Editor has a place to store approved pairs. See [Language resources](/platform/knowledge).
22. **MCP `list_issues`.** Agents can filter Board the same way the workspace list does, including status, type, priority, locale, assignee, and project. See [MCP tool reference](/platform/developers/mcp-tools).
