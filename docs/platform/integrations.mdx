## GitHub

Connect the GitHub App, enable the repositories you need, then configure [content sync](/platform/automation/content-sync) or an [automation trigger](/platform/automation/create-automation). Refreshing the repository list does not move files.

## Canva

Create a Canva connection with a personal token. Designers pick the native project in the Canva app. Jobs use that project's source and target languages. There is no separate Canva locale list. Follow [Localize Canva](/platform/connections/canva) to collect page files and apply existing translations.

## Figma

Create a Figma connection with a personal token. Designers pick the native project in the Figma plugin. Jobs use that project's source and target languages. Follow [Localize Figma](/platform/connections/figma) to upload source pages (collect only), translate, and apply one locale at a time.

## Sanity

Hyperlocalise supports two Sanity workflows:

- **Studio plugin**: Create a **Sanity Studio plugin** connection (personal access token). Editors OAuth from the `sanity-plugin-hyperlocalise` editor view or bulk tool, upload documents, translate, and write locale versions. Each OAuth grant is bound to the Studio origin. See [Localize Sanity Studio documents](/platform/connections/sanity-studio-plugin).
- **Automations**: Connect **Sanity** (Pipes) for scheduled or manual import of document sets, translation in Jobs, and **Push to Sanity** from the Content editor. See [Localize Sanity documents (automation)](/platform/connections/sanity).

## GitLab

An administrator can connect GitLab from **Integrations** through the authorization flow. Connected GitLab.com projects that you can clone with Reporter access or higher can be used as repository context in chat. Select a project or provide its project or merge-request URL.

Use **Use GitLab repo** in a manual or scheduled automation for repository analysis. Merge-request comment tools and GitLab content sync are not available in this workflow.

## Intercom

Connect Intercom from **Integrations**, then create a scheduled or manual automation with the **Translate Intercom Help Center articles** skill. Import writes markdown source files into a native project. **Push to Intercom** writes Intercom drafts. It does not publish. See [Localize Intercom Help Center articles](/platform/connections/intercom).

## Braze

Connect Braze from **Integrations** with a REST API key and REST cluster. Two workflows share that connection. Apply **Translate Braze Email Templates** or **Translate Braze Campaigns & Canvas** from Popular or Marketing. Do not attach both on one automation. Email Templates imports HTML and **Push to Braze** writes locale-suffixed library copies. Campaigns & Canvas imports tagged draft JSON maps and writes approved locales through the Translation API. Neither action publishes. See [Localize Braze](/platform/connections/braze).

## HubSpot

Emails, forms, blog posts, landing pages, and website pages import into a native project and push back as separate locale copies. Hyperlocalise translates the copy. HubSpot does not. Connect HubSpot from **Integrations** with OAuth or a private-app access token that has the `content` and `forms` scopes, then add the **Translate HubSpot content** template. See [Localize HubSpot](/platform/connections/hubspot).

## Other external services

Use the provider’s **Connect** action in **Integrations**, complete authorization or supply the requested credential, then select that tool in your automation. Availability and actions differ by provider; a catalog entry does not guarantee content sync.

For Ahrefs, connect the account and add the **Ahrefs** tool to the automation. For Zernio, save a valid API key, then select the **Zernio** tool and connection. Confirm the intended account and action before running tasks that publish or change external content.

## MCP server connections

To let an automation call tools on an external MCP server:

1. Open **Integrations** → **MCP Server**.
2. Enter a display name, HTTPS endpoint, transport (`http` or `sse`), and the required authentication.
3. Save and validate the connection.
4. Add the **MCP Server** tool to an automation and select the connection.

This connects Platform to an external server. To connect an agent such as Cursor to Platform, use the [hosted MCP server](/platform/mcp) instead.

## Slack Connect

Use the Slack integration for bot tools and automation notifications in your Slack workspace. The Slack Connect invitation on workspace **Overview**, when available, creates a shared support channel instead. See [Contact support](/platform/help/contact-support).

## API keys and tokens

Manage organization keys and personal tokens in [Settings](/platform/settings). If a connection fails or a resource is missing, use [Connection troubleshooting](/platform/help/connections).

## Translation management systems

Connect supported Crowdin, Lokalise, Phrase Strings, or Smartling workflows through
[Platform TMS integrations](/platform/tms). For repository and CI operations, use
the [all-in-one Hyperlocalise CLI](/cli/storage/overview). Provider-specific
commands and Platform connections have separate capabilities and credentials.
