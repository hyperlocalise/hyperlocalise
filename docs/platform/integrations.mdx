Connect the systems that hold your content or provide tools for your workflows. A connection gives access; you still need to configure the task or sync that uses it.

| Tool or workflow | Start here |
| --- | --- |
| GitHub repositories and events | [Connect GitHub](/platform/connections/github) |
| Canva and Figma translation | [Design tools](/platform/connections/design-tools) |
| Repository files through CI | [Connect the CLI](/platform/cli) |
| An AI agent working with Cloud | [Hosted MCP server](/platform/mcp) |
| Custom file and job integrations | [Public API](/platform/api) |

## GitHub

Connect the GitHub App, enable the repositories you need, then configure [content sync](/platform/automation/content-sync) or an [automation trigger](/platform/automation/create-automation). Refreshing the repository list does not move files.

## Canva

Create a Canva connection with a personal token, default project, and locales. Copy the one-time connection token into the app. Follow the [design-tools guide](/platform/connections/design-tools).

## Figma

The Figma plugin uses a personal token to extract text, create translation jobs, and pull completed locales. See [design tools](/platform/connections/design-tools) for access requirements and availability.

## GitLab

An administrator can connect GitLab from **Integrations** through the authorization flow. Connected GitLab.com projects that you can clone with Reporter access or higher can be used as repository context in chat. Select a project or provide its project or merge-request URL.

Use **Use GitLab repo** in a manual or scheduled automation for repository analysis. Merge-request comment tools and GitLab content sync are not available in this workflow.

## Other external services

Use the provider’s **Connect** action in **Integrations**, complete authorization or supply the requested credential, then select that tool in your automation. Availability and actions differ by provider; a catalog entry does not guarantee content sync.

For Ahrefs, connect the account and add the **Ahrefs** tool to the automation. For Zernio, save a valid API key, then select the **Zernio** tool and connection. Confirm the intended account and action before running tasks that publish or change external content.

## MCP server connections

To let an automation call tools on an external MCP server:

1. Open **Integrations** → **MCP Server**.
2. Enter a display name, HTTPS endpoint, transport (`http` or `sse`), and the required authentication.
3. Save and validate the connection.
4. Add the **MCP Server** tool to an automation and select the connection.

This connects Cloud to an external server. To connect an agent such as Cursor to Cloud, use the [hosted MCP server](/platform/mcp) instead.

## Slack Connect

Use the Slack integration for bot tools and automation notifications in your Slack workspace. The Slack Connect invitation on workspace **Overview**, when available, creates a shared support channel instead. See [Contact support](/platform/help/contact-support).

## API keys and tokens

Manage organization keys and personal tokens in [Settings](/platform/settings). If a connection fails or a resource is missing, use [Connection troubleshooting](/platform/help/connections).
