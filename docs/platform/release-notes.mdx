These notes cover Hyperlocalise Platform: translation, review, automations, language resources, integrations, and developer surfaces. Each month lists customer-visible changes and links to the guides that explain how to use them.

Hyperlocalise CLI version notes live in the [CLI changelog](/changelog).

## Months

- [2026 October](/platform/release-notes/2026-10): Unreal Engine gettext tags, merge identical strings, Office and Markdown file views, and translation QA.
- [2026 September](/platform/release-notes/2026-09): Hosted MCP, visual workflows, GitHub content sync, glossary and TM interchange, and website research.
- [2026 August](/platform/release-notes/2026-08): Personal access tokens, Figma, queue exports, hidden strings, subtitles, and Board issue IDs.
- [2026 July](/platform/release-notes/2026-07): All-files Content Editor, side-by-side review, TMS connectors, files API, and Knowledge.
- [2026 June](/platform/release-notes/2026-06): Content Editor workspace, Crowdin Phrase and Lokalise connections, teams, billing, and Canva.

Start with [Your first translation](/platform/getting-started) if you are new to the product. Use [Troubleshooting and support](/platform/help/overview) when a change does not match what you see in the workspace.
