Start with the step that failed. Keep the project, source path, target locale, and any job or run link available while investigating.

| Problem | Guide |
| --- | --- |
| File missing, rejected, or unavailable in the editor | [Upload problems](/platform/help/uploads) |
| Translation failed, stalled, or produced no output | [Translation failures](/platform/help/translation-failures) |
| Terms, placeholders, or tone are wrong | [Translation quality](/platform/help/quality) |
| Automation did not run or sync did nothing | [Automation problems](/platform/help/automations) |
| Repository, token, or external service cannot connect | [Connection problems](/platform/help/connections) |
| Invitation, project, or action is unavailable | [Workspace access](/platform/help/access) |
| Work is blocked by usage or subscription settings | [Billing and usage](/platform/workspace/billing) |

## Before retrying

Read the error and check whether the operation already produced output. An external write can complete even if the response is interrupted. Repeating uploads, job requests, or workflow actions can create additional work.

If these checks do not resolve the problem, [contact support](/platform/help/contact-support) with the relevant links and error text.
