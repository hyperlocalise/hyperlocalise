title: "Contact support"
description: "Send the context needed to investigate a Platform problem without sharing credentials."
---

Email [minh@hyperlocalise.com](mailto:minh@hyperlocalise.com) when the troubleshooting guides do not resolve a problem.

## Include the relevant details

Copy this template and omit anything that does not apply:

```text
Workspace and project:
What I expected:
What happened:
Steps to reproduce:
Source file path and target locale:
Job, automation run, or issue link:
Time of failure and timezone:
Exact error message:
What I have already tried:
```

Include a screenshot or a small sanitized sample if it helps explain a parsing or formatting problem. Remove API keys, personal tokens, connection secrets, and private content that is not needed to reproduce the issue.

For billing problems, include the workspace and the displayed subscription or usage message. For access problems, include the invited account email and the missing workspace or project.

## Slack Connect

If workspace **Overview** offers a Slack Connect invitation, request it and check the email address on your Hyperlocalise account. Accept the invitation to link the shared channel with your workspace. If you need another invitation, use the option when it becomes available again.

Slack Connect is a shared support channel. It is separate from installing the Slack integration used by automations and bot tools.
