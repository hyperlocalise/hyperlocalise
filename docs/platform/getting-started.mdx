---
title: "Your first translation"
description: "Use a small sample file to create a project, translate into French, review the result, and download it."
---

Take one source file through upload, translation, review, and download. This walkthrough uses a native project with English (`en-US`) source text and French (`fr-FR`) as the target.

## Before you start

Sign in to [Hyperlocalise](https://www.hyperlocalise.com) and select your workspace. You need permission to create a project and request translation, available workspace usage, and an authorized reviewer for approval. If a teammate invited you, accept using the invited email address.

If your content lives in another TMS, start with [connected projects](/platform/tms). For a role-specific path, see [managers](/platform/getting-started/managers), [translators and reviewers](/platform/getting-started/translators), or [developers](/platform/getting-started/developers).

## 1. Prepare the sample

[Download checkout.json](/samples/checkout.json), or save this content as `checkout.json`:

```json
{
    "checkout.title": "Your order",
    "checkout.continue": "Continue to payment",
    "checkout.back": "Back to cart"
}
```

Keep the keys unchanged. Only the values need translation.

## 2. Create a project

Open **Projects** and select **Create project** (or **Create native project** in a TMS-first workspace). Name it `Checkout`, set the source locale to `en-US`, and keep only `fr-FR` as the target. Select **Save project**.

You should see **Project created** and the project in the list. Open it and confirm its languages. See [Create a project](/platform/projects/create-project) for detailed setup and recovery steps.

## 3. Upload the source file

Open **Files**, select **Add files**, and choose `checkout.json`. Review **Ready to upload**, then select **Upload**. Wait for completion and confirm the file appears.

Uploading stores source content. It does not generate translations unless a matching automation is active. For this walkthrough, check whether an automation already handles uploads before submitting the same work manually.

If the file is missing, follow [upload troubleshooting](/platform/help/uploads).

## 4. Request a translation

Open **New Request** under **Agents** and enter:

```text
Translate checkout.json in the Checkout project from en-US to fr-FR.
Keep the three translation keys unchanged. Translate only their values.
Leave the translations for human review.
```

Check the selected project and available tools before proceeding. Follow the request in **My Jobs** or the project's jobs. Wait for generation to finish; see [Start a translation](/platform/translation/start) and [job recovery](/platform/translation/jobs) if it fails.

## 5. Review the result

Open `checkout.json` from **Files**, select `fr-FR`, and inspect its three strings in the [Content Editor](/platform/cat). Confirm the target values are French and fit a checkout interface. For example, “Your order” might become “Votre commande”; wording can vary with your guidance.

Check **Untranslated** and **Has issues** as well as **Needs review**. Ask an authorized reviewer to approve the final text. A completed generation job does not mean the translations have been approved.

## 6. Download and verify

Open **Download translations** from the project's files view. Select `checkout.json` and `fr-FR`, then select **Download**.

Open the resulting JSON file. Confirm all three keys remain unchanged and their values contain the reviewed French text. Load it in your application before publishing. See [Download translated files](/platform/translation/download) if output is missing or incorrect.

<Note>
The Content Editor's queue download exports a filtered segment list. Use the project's **Download translations** action when you need the translated source-file format.
</Note>
