---
title: "Your first translation"
description: "Create a Platform project and take one source file through translation, review, and download."
---

Start with a small source file and one target language. This walkthrough uses a native Hyperlocalise project, where Platform stores your files and translations. Files and languages in a connected TMS project are managed by that provider.

## 1. Sign in and choose a workspace

Open [Hyperlocalise](https://www.hyperlocalise.com), sign in, and select your organization. If a teammate invited you, accept the invitation using the invited email address. Ask an administrator for project access if the workspace is empty.

## 2. Create a project

Open **Projects**, create a project, enter a recognizable name, and choose the source and target locales. Select **Save project**. See [Create a project](/platform/projects/create-project) for language and access details.

## 3. Upload a source file

Open the project’s **Files**, select **Add files**, choose your file, then select **Upload**. Wait for the upload to finish and confirm that the file appears. Uploading makes the source available; generation is a separate step.

## 4. Request a translation

Open **New Request** under **Agents**. Specify the project, source path, and target locale. For example:

```text
Translate checkout.json in the Checkout project from en to fr.
Use the project guideline and glossary. Leave the translations for review.
```

Check the selected project and tools before proceeding with the request. Follow the work in **My Jobs** or the project’s jobs. See [Start a translation](/platform/translation/start) if generation is unavailable or fails.

## 5. Review the result

Open the source file in **Files**, choose the target locale, and review it in the [Content Editor](/platform/cat). Check terminology, placeholders, and context before approving. A completed generation job does not mean a reviewer has approved every translation.

## 6. Download translations

Open **Download translations** from the project’s files view. Select your source file and target locale, then select **Download**. Check the resulting file in your application before publishing it.

The editor’s queue download exports a filtered segment list. Use [Download translations](/platform/translation/download) when you need the translated source-file format.
