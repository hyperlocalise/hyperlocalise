Guideline, glossaries, and translation memories are the shared memory of your content operations.

Use a guideline for tone and context, a glossary for required terms, and a translation memory for reusable source/target sentence pairs. Review suggestions in context before approving them.

Cloud splits this into three sidebar items. **Guideline** is the free-form context page. **Glossaries** and **Translation Memories** are structured term and TM stores.

## Guideline

Open **Guideline** in the organization **Workspace** group, or on a project.

Upload style guides, product notes, and market instructions. Use workspace guidance for shared rules and project guidance for content-specific context. See [Add translation guidelines](/platform/knowledge/guidelines) for supported files and examples.

## Glossaries

Open **Glossaries**. Create workspace glossaries, or sync provider term bases. Provider glossaries stay read-only.

1. Click **Create glossary**.
2. Name it and set source and target locales.
3. Add terms. Mark forbidden terms so the Content Editor and agents avoid them.
4. Link the glossary to the projects that should enforce it.

The Content Editor uses glossary hits as suggestions while you edit. Automations can query the same terms during a run.

Import and export native glossaries as **TBX**, **CSV**, or **XLSX** from the glossary actions menu. See [Glossary import and export](/platform/glossary-import-export). Provider glossaries stay read-only in Cloud.

## Translation memories

Open **Translation Memories**.

You can keep a workspace TM or connect an **External TMS** memory. The table shows **Provider**, linked project, and segment counts.

Create a workspace memory, then import or grow it from approved translations in the Content Editor. The Content Editor uses matching segments as suggestions. Agents can query the same memory during a run.

Import **CSV** or **TMX** from the memory detail page, and export the full memory or a single locale pair in either format. See [Translation memory import and export](/platform/translation-memory-import-export).
