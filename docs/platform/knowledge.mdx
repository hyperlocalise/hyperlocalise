Guideline, glossaries, and translation memories are the shared memory of your content operations.

Add the terms and memories your team already trusts so CAT and automations reuse them.

Cloud splits this into three sidebar items. **Guideline** is the free-form context page. **Glossaries** and **Translation Memories** are structured term and TM stores.

## Guideline

Open **Guideline** in the organization **Workspace** group, or on a project.

Organization **Guideline**: "Give every workflow the language, market, compliance, and go-to-market context it needs."

Project **Guideline**: "Give this project's workflows the language, market, and product context they need."

Upload style guides, product notes, or other files there. Automations and chat read that context when they translate.

## Glossaries

Open **Glossaries**. Create first-party workspace glossaries, or sync provider term bases. Provider glossaries stay read-only.

1. Click **Create glossary**.
2. Name it and set source and target locales.
3. Add terms. Mark forbidden terms so CAT and agents avoid them.
4. Link the glossary to the projects that should enforce it.

CAT uses glossary hits as suggestions while you edit. Automations can query the same terms during a run.

## Translation memories

Open **Translation Memories**.

You can keep a workspace TM or connect an **External TMS** memory. The table shows **Provider**, linked project, and segment counts.

Create a workspace memory, then import or grow it from approved CAT work. CAT uses matching segments as suggestions. Agents can query the same memory during a run.
