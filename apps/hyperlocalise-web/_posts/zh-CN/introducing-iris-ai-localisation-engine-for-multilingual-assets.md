大多数本地化工具止步于文本。

他们负责处理产品中的字符串、帮助中心的文章以及网站页面。然后营销活动上线了，而人们最先看到的内容却仍然只有一种语言：主视觉横幅、社交媒体广告、发布视频和配音。

这些素材即便会本地化，也都是靠人工完成。每进入一个市场，设计师就得重新打开文件。字幕变长时，剪辑师就要重新剪辑视频以适配。代理机构还得重新录制配音。每个市场都会多耗上几天，而品牌认可的用语则在需求简报到最终导出之间不知所踪。

今天，我们正式推出 **[Iris](/iris)**，这是一款面向多语言素材的 AI 本地化引擎。Iris 可直接在你的 Mac 上为每种语言和市场创建并调整图像、视频、语音和音频。

> **理念很简单：每项资产都应让人感到贴近本地，而不只是周围的文字。**

## Iris 的功能

Iris 将过去需要四种不同工具、通常还要靠代理机构完成的四项工作整合到了一起。

| 功能 | 作用 |
| --- | --- |
| **图片、横幅和社交广告** | 重写横幅、社交广告和产品图中的文案，让每个版本读起来都像是为当地市场量身打造的 |
| **视频** | 为每个市场的产品视频和视频广告添加字幕并进行本地化，无需返回剪辑室 |
| **旁白与配音** | 使用演讲者本人的声音为旁白配音，或根据不同受众的语言生成新的旁白 |
| **布局检查** | 在较长的德语标题撑坏横幅之前，发现文字截断和布局错乱 |

### 看起来像是本地制作的图片

给 Iris 一张已完成的图片，例如横幅、快拍或已嵌入文案的产品图。它会读取图片中的文字，使用工作区术语进行翻译，并在相同的位置、以相同的样式和布局重新绘制审核通过的文案。

开始时不需要分层设计文件或干净的背景底图。结果会作为面向新市场的新版本与原版并排显示，方便你逐一比较各个语言版本。

如需查看完整指南，请阅读[如何为每个市场本地化图片广告和社交媒体创意](/blog/how-to-localise-image-ads-and-social-creatives-for-every-market)。

### 无需重新剪辑视频

Iris 会针对每个市场翻译视频的转录文本，并让字幕时间与原视频保持一致。它会在说话者自然停顿处换行，而不是按固定字数换行，并将名称、数字和单位放在一起。

当译文行在屏幕上过宽时，Iris 会将其拆分成多个字幕，而不是不断缩小文字，直到没人看得清。

如果你提供已完成的视频，例如代理商母版或社交媒体剪辑，Iris 可以先将其重建。它会读取剪辑内容和画面中嵌入的文字，然后重建所有屏幕文字，以便进行翻译。

### 匹配的声音

Iris 可以为每个市场的语音配音，同时保留说话者本人的声音；如果有人出镜讲话，还能同步口型。制作新的旁白时，Iris 会翻译稿件，并用适合该市场的声音朗读。如果你的品牌有自己的声音，比如创始人或固定旁白，那么这个声音可以用各种语言说话。

品牌和产品名称是配音中常见的问题。Iris 会按照词汇表中的拼写来读它们，这样你只需修正一次错误的读法，不必在每个脚本中重复修改。

### 每种文字系统中的布局检查

翻译后的文本长度会有所变化。德语、芬兰语和法语通常比英语长 20–35%。中文和日语通常更短。阿拉伯语和希伯来语从右向左阅读。泰语、日语和中文的词语之间没有空格，因此换行时不会按词间空格处理。

Iris 会检查每个市场的文本是否溢出、字幕是否超出屏幕、字符是否缺失，以及字体是否支持相应文字。它会展示文案最多的画面，方便人工在导出前审核每种语言版本。

## 遵循与 Hyperlocalise 其他部分相同的品牌规则构建的

Iris 不是独立的翻译工具。它与 [Hyperlocalise 网页应用](/product/multilingual-content-studio)使用同一工作区：

- **术语表。** 已批准的译法必须使用，禁用的译法在所有场景中均不得使用：屏幕文案、配音脚本和图像提示词。
- **翻译记忆。**已批准的文案会重复使用，而不是重新翻译。
- **[指南](/product/guidelines)。** 文案可根据您上传的品牌和合规文件进行核对。
- **审批结果会成为记忆。**当你批准某个语言版本后，工作区会记住已批准的文案，供下次使用。

这就是翻译创意内容与本地化创意内容的区别。如果文案用了法务上季度就禁用的术语，再流畅也不够。我们曾写过为什么[上下文比流畅度更重要](/blog/ai-translation-is-not-enough-context-aware-localisation)，也写过如何[在不同市场保持品牌语调和术语一致](/blog/how-to-keep-brand-voice-and-terminology-consistent-across-markets)。Iris 对图片和声音也采用同样的规则。了解具体做法，请参阅[如何在图片和视频中保持术语表和品牌语调一致](/blog/keeping-glossary-and-brand-voice-consistent-in-images-and-video)。

## 市场，而不只是语言。

Iris 面向不同市场，而不仅仅是不同语言。西班牙的西班牙语（`es-ES`）和墨西哥的西班牙语（`es-MX`）在词汇、语气和格式上都不相同。价格、日期和复数形式遵循各自区域设置的规则，而不是把翻译片段拼凑在一起。

这就是 [超本地化](/blog/hyperlocalisation-why-global-growth-needs-more-than-translation)的核心理念：调整沟通方式，让内容在每个市场都显得自然可信，而不是逐字替换。

## 适用于您的 AI 智能体

Iris 内置 MCP 服务器，因此 Claude Code 等智能体可以使用其完整工具集。这包括打开创意素材、生成和本地化图像、为视频添加字幕和配音、检查版式，以及读取你的术语表和翻译记忆库。

你可以让你的智能体“使用我们的术语表，为法国、德国和日本本地化这场营销活动”，并在 Mac 上的 Iris 应用中查看工作过程。这与[什么是翻译智能？](/blog/what-is-translation-intelligence)中介绍的是同一智能层，只是应用于创意素材。有关设置步骤和提示词示例，请阅读[通过 MCP 在 Claude Code、Cursor 和其他智能体中使用 Iris](/blog/using-iris-from-claude-code-and-other-agents-over-mcp)。

## Iris 适合哪些人使用？

- **负责多个市场付费社交和展示广告的效果营销与增长营销人员**，他们需要今天就拿到本地化版本，而不是等到下一个冲刺周期。
- **希望每个市场都能获得与源营销活动同等品质的品牌和创意团队。**
- **生命周期和内容团队**本地化产品视频、新手引导短片和发布宣传片。
- **代理机构**，负责交付多市场营销活动，并希望不再把同一份素材重复制作十遍。
