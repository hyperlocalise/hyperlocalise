เอเจนต์เขียนโค้ดเก่งขึ้นมากในการปรับผลิตภัณฑ์ให้เข้ากับแต่ละตลาด โดยดึงข้อความมาต่อเข้ากับ `react-intl` เปิด pull request และตรวจสอบรูปพหูพจน์ เราเคยเขียนถึงเวิร์กโฟลว์นี้สำหรับ [GitHub](/blog/github-localisation-workflow-from-pull-request-to-multilingual-release) และสำหรับ [React Intl และ ICU](/blog/react-intl-icu-localisation-workflow-extract-sync-and-review) ด้วย

จากนั้นตัวผลิตภัณฑ์ที่กำลังจะเปิดตัวก็ต้องมีวิดีโอเปิดตัว ชุดแบนเนอร์สำหรับโซเชียลมีเดีย และเดโมผลิตภัณฑ์ในหกภาษา แต่เอเจนต์กลับช่วยอะไรไม่ได้ เครื่องมือสร้างสรรค์ต่าง ๆ ออกแบบมาให้คนคลิกไปตามไทม์ไลน์หรือบนแคนวาส แต่ไม่มีอะไรที่เอเจนต์เรียกใช้งานได้เลย

**[Iris](/iris)** ทำงานแตกต่างออกไป ความสามารถทุกอย่างในแอปยังเป็นเครื่องมือ MCP ด้วย เพียงเชื่อมต่อเอเจนต์ของคุณครั้งเดียว ก็สามารถเปิดงานครีเอทีฟ อ่านข้อความในภาพ ปรับให้เหมาะกับแต่ละตลาด ทำคำบรรยายและพากย์วิดีโอ ตรวจสอบเลย์เอาต์ รวมถึงอ่านอภิธานศัพท์และหน่วยความจำการแปลของคุณได้ ทั้งหมดนี้ทำงานในแอป Iris บน Mac ของคุณ คุณจึงดูการทำงานและเข้าไปจัดการได้ทุกเมื่อ

โพสต์นี้จะอธิบายว่าการทำเช่นนั้นเป็นอย่างไร วิธีเชื่อมต่อ และวิธีมอบหมายงานปรับเนื้อหาให้เข้ากับท้องถิ่นเชิงสร้างสรรค์ที่เอเจนต์สามารถทำให้เสร็จได้จริงแก่เอเจนต์

## เหตุใดการเข้าถึง MCP จึงสำคัญต่องานสร้างสรรค์

เครื่องมือสร้างสรรค์ส่วนใหญ่มีปุ่มส่งออก และบางเครื่องมือมี API สำหรับงานเดียว เช่น “แปลไฟล์คำบรรยายนี้” แต่ไม่มีเครื่องมือใดที่ให้เอเจนต์ทำเวิร์กโฟลว์ทั้งหมดได้

การปรับชิ้นงานโฆษณาหนึ่งชิ้นให้เข้ากับแต่ละตลาดต้องผ่านการตัดสินใจหลายขั้นตอนต่อเนื่องกัน: อ่านข้อความ ตรวจสอบคำศัพท์ที่ได้รับอนุมัติ แปล วาดใหม่หรือปรับเวลา ตรวจสอบทุกตลาด แก้ไขสิ่งที่ผิดพลาด และขอให้คนอนุมัติ เอเจนต์จะรับผิดชอบกระบวนการทั้งหมดนี้ได้ก็ต่อเมื่อเข้าถึงทุกขั้นตอนได้

Iris ทำให้เข้าถึงทั้งหมดนี้ได้ เซิร์ฟเวอร์จะแสดงรายการเครื่องมือทั้งหมดให้เอเจนต์ที่เชื่อมต่อทุกตัว พร้อมอธิบายอินพุตและเอาต์พุตของแต่ละเครื่องมือด้วย JSON Schema นอกจากนี้ยังมีหน้าคู่มือทักษะชุดเดียวกับที่ผู้ช่วยในตัวของ Iris ใช้ ซึ่งครอบคลุมการปรับให้เข้ากับท้องถิ่น การตัดต่อวิดีโอ กราฟิกเคลื่อนไหว และคำศัพท์เฉพาะทาง เพื่อให้เอเจนต์เรียนรู้ขั้นตอนการทำงานที่ถูกต้องก่อนเริ่ม แทนที่จะต้องเดาเอง

นั่นหมายความว่าคุณสามารถมอบหมายงานโดยระบุผลลัพธ์ที่ต้องการ (“ปรับแคมเปญนี้ให้เหมาะกับฝรั่งเศส เยอรมนี และญี่ปุ่น”) แทนการแจกแจงทุกขั้นตอนได้

## สิ่งที่เอเจนต์ทำได้ผ่าน Iris

| พื้นที่ | สิ่งที่เอเจนต์ทำได้ |
| --- | --- |
| **รูปภาพ** | อ่านข้อความที่ฝังอยู่ในแบนเนอร์หรือโฆษณาบนโซเชียล แปลข้อความนั้น แล้วจัดวางข้อความที่ได้รับอนุมัติใหม่สำหรับแต่ละตลาด |
| **วิดีโอ** | สร้างข้อความบนหน้าจอของวิดีโอที่เสร็จแล้วขึ้นใหม่ แปลข้อความ และสร้างคำบรรยายที่กำหนดเวลาให้ตรงกับต้นฉบับ |
| **เสียง** | พากย์เสียงด้วยเสียงของผู้พูดเอง สร้างเสียงพากย์ใหม่สำหรับแต่ละตลาด และซิงค์การขยับริมฝีปาก |
| **คำศัพท์เฉพาะ** | ค้นหาคำศัพท์ในอภิธานศัพท์ คำแปลที่อนุมัติและห้ามใช้ รวมถึงหน่วยความจำการแปลสำหรับข้อความทุกชิ้น |
| **แนวทาง** | ตรวจสอบข้อความกับเอกสารแบรนด์และเอกสารการปฏิบัติตามข้อกำหนดที่คุณอัปโหลด พร้อมระบุแหล่งที่มาของข้อค้นพบ |
| **คุณภาพ** | ตรวจสอบแต่ละตลาดว่ามีข้อความล้น คำบรรยายที่หลุดออกนอกหน้าจอ หรือตัวอักษรหายไปหรือไม่ และดูตัวอย่างเฟรมที่มีข้อความมากที่สุด |
| **พื้นที่ทำงาน** | อ่านโปรเจ็กต์แปล งาน รายงาน QA และระบบอัตโนมัติในพื้นที่ทำงาน Hyperlocalise ของคุณ |

เอเจนต์ใช้คลังคำศัพท์และหน่วยความจำการแปลชุดเดียวกับทุกคนในเวิร์กสเปซของคุณ เมื่อเอเจนต์ปรับแบนเนอร์ให้เหมาะกับแต่ละภาษา ระบบจะใช้คำที่ได้รับอนุมัติและบล็อกคำต้องห้าม เช่นเดียวกับเมื่อมีคนใช้แอปนี้ด้วยตนเอง

## เชื่อมต่อเอเจนต์ของคุณ

Iris จะเรียกใช้เซิร์ฟเวอร์ MCP บนเครื่องของคุณขณะที่แอปเปิดอยู่ โดยเข้าถึงได้จากเครื่องของคุณเท่านั้นที่ที่อยู่คงที่นี้:

```text
http://127.0.0.1:4747/mcp
```

### วิธีที่รวดเร็ว

ใน Iris ให้เปิด **เชื่อมต่อเอเจนต์ผ่าน MCP** Iris จะตรวจหาเอเจนต์ที่ติดตั้งบน Mac ของคุณ แล้วใช้ **เชื่อมต่อ** เพื่อเพิ่มเซิร์ฟเวอร์ลงในไฟล์กำหนดค่าของเอเจนต์แต่ละตัว รองรับ Claude Code, Claude Desktop, Cursor, VS Code (Copilot), GitHub Copilot CLI, Codex, Gemini CLI, Windsurf, Cline, Roo Code, Amp, OpenCode และอีกหลายรายการ

### ด้วยมือ

หากคุณต้องการเพิ่มด้วยตัวเอง ให้ลงทะเบียนเซิร์ฟเวอร์ MCP แบบ HTTP ที่ชื่อ `hyperlocalise-iris` สำหรับ Claude Code:

```bash
claude mcp add --scope user -t http hyperlocalise-iris http://127.0.0.1:4747/mcp
```

สำหรับ Cursor ให้เพิ่มลงใน `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "hyperlocalise-iris": {
      "url": "http://127.0.0.1:4747/mcp"
    }
  }
}
```

ไคลเอนต์ที่เปิดใช้ได้เฉพาะเซิร์ฟเวอร์บรรทัดคำสั่งในเครื่อง สามารถเข้าถึง URL ผ่านบริดจ์ทั่วไป เช่น `mcp-remote` ได้

### ตรวจสอบการเชื่อมต่อ

เมื่อเปิด Iris อยู่ ให้ถามเอเจนต์ของคุณ:

```text
What screen do I have open in Hyperlocalise? Don't change anything.
```

ควรอธิบายสิ่งที่แสดงอยู่บนหน้าจอในแอป หากไม่มีเครื่องมือ ให้ตรวจสอบว่า Iris กำลังทำงานอยู่ เซิร์ฟเวอร์จะทำงานอยู่เฉพาะตอนที่เปิดแอปเท่านั้น เครดิตฟรี

> **MCP server ของ Iris แตกต่างจาก [Hyperlocalise MCP server](/use-cases/localisation-for-ai-coding-agents) ที่โฮสต์ไว้** เซิร์ฟเวอร์ที่โฮสต์ไว้ที่ `hyperlocalise.com/mcp` ช่วยให้เอเจนต์เข้าถึงโปรเจ็กต์ ไฟล์ต้นฉบับ และคีย์การแปลของคุณได้จากทุกที่ ส่วนเซิร์ฟเวอร์ในเครื่องของ Iris จะเพิ่มงานสร้างสรรค์ (ภาพ วิดีโอ และเสียง) บน Mac ของคุณ หลายทีมเชื่อมต่อทั้งสองเซิร์ฟเวอร์เข้าด้วยกัน

## มอบหมายงานที่เอเจนต์ทำให้เสร็จได้

เอเจนต์ทำงานได้ดีที่สุดเมื่อมีผลลัพธ์ที่ชัดเจน ขอบเขตงานที่กำหนดไว้ และจุดที่ให้คนตรวจสอบผลลัพธ์ ตัวอย่างพรอมป์ต์ที่ใช้ได้ดี:

**แปลแบนเนอร์เป็นภาษาท้องถิ่น**

```text
Open the summer-sale banner in Iris and localise it for fr-FR, de-DE and ja-JP.
Use our glossary and keep "Pro plan" in English. Check each market for overflow and
show me the results side by side. Don't export.
```

**ใส่คำบรรยายวิดีโอผลิตภัณฑ์**

```text
Subtitle the onboarding video for es-MX and pt-BR. Split cues at natural pauses,
keep product names together, and flag any cue that overflows the caption area.
```

**ตรวจสอบข้อความก่อนเผยแพร่**

```text
Look up the glossary terms in this ad copy for de-DE, then check the German
translation against our brand guidelines. List anything that breaks a rule,
with the guideline it breaks.
```

เปลี่ยนข้อมูลการเปิดตัวให้เป็นสื่อสำหรับวันเปิดตัว

```text
Read the release notes in this PR, write a 15-second launch video script, and build it
in Iris. Then localise the on-screen copy for our five launch markets and show me
a preview of each.
```

จุดนี้แหละที่เรื่องนี้เริ่มน่าสนใจ เอเจนต์ตัวเดียวกับที่ปล่อยฟีเจอร์นี้ยังสร้างสื่อเปิดตัวสำหรับทุกตลาดได้ โดยใช้คำศัพท์ชุดเดียวกับที่ผลิตภัณฑ์ใช้ด้วย

## ให้มนุษย์มีส่วนร่วมตลอดกระบวนการ

Iris ออกแบบมาให้เอเจนต์เป็นผู้ดำเนินการ และให้บุคคลเป็นผู้อนุมัติ

- **คุณมองเห็นการทำงานได้** เอเจนต์ทำงานในแอป Iris บน Mac ของคุณ คุณจึงเห็นชิ้นงานเปลี่ยนแปลงไปเรื่อย ๆ และเข้าไปช่วยได้ทุกเมื่อ】【。
- **ดูตัวอย่างก่อนส่งออก** เอเจนต์จะได้รับคำแนะนำให้แสดงเฟรมตัวอย่าง และรอจนกว่าคุณจะขอให้ส่งออกไฟล์ฉบับสุดท้าย
- **การเปลี่ยนแปลงอภิธานศัพท์ต้องได้รับความเห็นชอบ** ระบบแนะนำให้เอเจนต์ยืนยันคำศัพท์ใหม่ในอภิธานศัพท์กับคุณก่อนเพิ่ม แทนที่จะเปลี่ยนฐานคำศัพท์ของคุณโดยไม่แจ้งให้ทราบ
- **การอนุมัติช่วยให้เวิร์กสเปซเรียนรู้** เมื่อคุณอนุมัติตลาด ข้อความที่อนุมัติจะถูกบันทึกไว้ในหน่วยความจำของเวิร์กสเปซ เพื่อให้การทำงานของเอเจนต์ครั้งถัดไปเริ่มต้นจากข้อความนั้น

นี่คือหลักการเดียวกันที่อยู่เบื้องหลังเวิร์กโฟลว์ทุกแบบของ Hyperlocalise ซึ่งเราได้กล่าวถึงใน [คุณควรสร้างเอเจนต์ด้านการแปลให้เองหรือไม่](/blog/should-you-build-your-own-localisation-agent): ส่วนที่ยากไม่ใช่การสร้างผลลัพธ์ แต่คือการรักษาบริบท ควบคุมคุณภาพ และเรียนรู้จากความคิดเห็นของมนุษย์.

## เริ่มต้นใช้งาน

1. **[ดาวน์โหลด Iris](/iris)** สำหรับ Mac ฟรี การสร้างใช้เครดิต AI ซึ่งรวมอยู่ในแพ็กเกจแบบชำระเงิน เริ่มต้นที่ $20 ต่อเดือน
2. เปิด **เชื่อมต่อเอเจนต์ผ่าน MCP** แล้วเชื่อมต่อเอเจนต์ที่คุณใช้
3. ขอให้เอเจนต์ของคุณปรับชิ้นงานหนึ่งชิ้นที่คุณจะเผยแพร่ในเดือนนี้ให้เหมาะกับท้องถิ่น
