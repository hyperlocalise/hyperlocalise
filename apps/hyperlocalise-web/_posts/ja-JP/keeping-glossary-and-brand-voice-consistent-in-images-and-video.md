用語を重視するチームの多くは、すでに大変な作業を終えています。用語集があり、製品名の表記ルールもあります。法務部門には、特定の市場では決して使ってはならない表現のリストがあります。ローカライズのワークフローでチェックされるため、製品のUI、ヘルプセンター、ウェブサイトにはこれらのルールが反映されています。

その後、キャンペーン用の素材が配信されます。

ドイツ語のバナーでは、英語のままにすると決めた製品名が翻訳されています。日本語字幕では、ブランドが2年前に使わなくなったくだけた文体が使われています。スペイン語のナレーションでは会社名の発音が間違っており、その後のナレーションもすべて同じです。それぞれ別々に収録されたためです。フランス語のSNS広告では、法務部門が前四半期に削除した「最高」という訴求が復活しています。

これらはいずれも翻訳の失敗ではありません。どの翻訳も自然です。これらは**一貫性の問題**であり、ルールを管理するシステムの外でクリエイティブアセットがローカライズされるために発生します。

用語ガバナンスの設定方法については、[ブランドボイスと用語を市場間で一貫させる方法](/blog/how-to-keep-brand-voice-and-terminology-consistent-across-markets)で解説しました。この記事では次のステップとして、同じルールを画像、動画、音声に適用する方法を取り上げます。

## クリエイティブアセットがずれていく理由

テキストコンテンツはゆっくり変化します。一方、クリエイティブアセットは3つの理由から急速に変化します。

- **これらはローカリゼーションのワークフロー外で作られています。**デザイナーがバナーに翻訳文を入力し、編集者がタイムラインに字幕を貼り付け、声優がメールで届いた台本を読みます。どの工程でも用語集は確認されません。
- **すべてのアセットが一度きりです。**製品内の文字列は一度翻訳すれば再利用できます。バナーの見出しはサイズ、マーケット、キャンペーンごとに入力し直すため、コピーするたびに間違いが起きる可能性があります。
- **音声にはスペルチェックがありません。** ブランド名を間違って発音しても、台本が正しければテキストレビューをすべて通過してしまいます。お客様に指摘されるまで、誰も気づきません。

解決策はレビューを増やすことではありません。クリエイティブのローカライズでも、ほかのすべてと同じ信頼できる情報源を使うことです。

## 1つのワークスペースに、1つのルールセット

**[Iris](/iris)** は、画像、動画、音声をローカライズする Hyperlocalise アプリです。独自の用語集は持たず、Web アプリと同じワークスペースを参照します：

| リソース | クリエイティブアセットで制御する内容 |
| --- | --- |
| **用語集** | 承認済みの翻訳が適用され、禁止用語は画面上の文言、ナレーション原稿、画像プロンプトでブロックされます |
| **翻訳メモリ** | タグライン、CTA、オファー条件など、すでに承認済みの文言を再翻訳せずに再利用します |
| **ガイドライン** | アップロードされたブランドおよびコンプライアンス関連文書に照らして文言をチェックし、該当するルールを示す指摘を提示します |
| **発音** | 用語の読み方を用語集に記載できるため、すべてのナレーションで同じ発音にできます |
| **ワークスペースメモリ** | 承認済みの市場がメモリに反映されるため、次のキャンペーンはそれを基に開始できます |

用語集の用語を一度変更すれば、次のバナー、字幕、ナレーションだけでなく、製品やウェブサイトにも反映されます。同期が必要な別のリストはありません。

## 画像：画像内のテキスト

Irisが画像をローカライズする際は、画像に埋め込まれた見出し、オファー、CTA、注意書きなどのコピーを読み取り、それぞれの表現を翻訳前に用語集で確認します。承認済みの用語はそのまま使用し、使用禁止の用語は除外します。翻訳メモリに登録されているコピーは再利用します。

これは、すべてのキャンペーンで繰り返し使われる要素にとって特に重要です：

- **製品名とプラン名。**用語集で「Pro plan」を英語のままにする場合は、すべてのバナーでも英語のままにしてください。
- **繰り返し使用するCTA。**「無料トライアルを始める」には、すべての市場・サイズで同じ承認済みの訳を使い、微妙に異なる訳を5種類も作らない。
- **タグライン。**市場ごとに承認されたタグラインは、キャンペーンごとに再翻訳せず、そのまま使用します。
- **主張。** 禁止された主張は、コピー内と画像生成に使用するプロンプト内の両方でブロックされるため、生成されたビジュアルを通じて再び表示されることはありません。

画像制作の全ワークフローについては、[各市場向けの画像広告とソーシャルクリエイティブのローカライズ方法](/blog/how-to-localise-image-ads-and-social-creatives-for-every-market)をご覧ください。

## 動画：画面上の文言と字幕

動画では、用語は2か所に表示されます。タイトル、ローワーサード、エンドカードなどの画面上のテキストと、字幕です。

**画面上のコピー。**Irisは、画面上のすべての文言を、翻訳者向けの注記付きの翻訳対象メッセージとして扱います。たとえば「エンドカードのCTA、18文字以内、命令形」のような注記です。注記は文言と一緒に引き継がれるため、ブランドの意図や利用可能なスペースに合わせて翻訳でき、用語集もほかの箇所と同じように適用されます。

**字幕。** Irisが映像を書き起こす際、用語集の用語を認識するため、製品名をよく似た一般的な単語ではなく、正しい表記で出力できます。翻訳後の字幕にも同じ用語が使われます。また、名前、数字、単位が同じ行に収まるようにするため、製品名が2つの字幕に分かれることはありません。

**文体。** 丁寧な呼びかけかくだけた呼びかけか（`tu`/`vous`、`du`/`Sie`）は、翻訳上の細部ではなくブランド上の判断です。ブリーフとガイドラインで指定し、承認前に各市場のコピーで一貫性を確認してください。

## 音声：発音とブランドボイス

一貫性を保つのが最も難しいのが声のトーンです。Irisは、テキストツールにはできないことを実現します。

### 発音は用語集にあります。

ナレーションでブランド名や製品名が正しく発音されない場合、通常はその台本だけ発音どおりに綴り直して修正します。ところが、次の台本ではまた間違って発音されてしまいます。

Irisでは、発音も用語集のエントリーの一部です。用語には、原文の言語と各翻訳先の言語での読み方を設定できます。対応する音声モデルは、読み上げるたびにその発音を使います。名前を一度修正すれば、その後はどの市場でも、すべてのナレーションで正しく発音されます。

### どの言語でも一貫した語り口で

ブランド独自の声（創業者、いつものナレーター、誰もが知るプレゼンターなど）がある場合、Irisはあらゆる言語でその声を使えます。既存の映像に吹き替えを加える場合も、市場ごとに話者本人の声を保ちます。

新しい市場向けの音声は、「30代の、ゆったりと話す温かみのあるメキシコ系スペイン語のナレーター」のように説明を入力すれば、Irisが作成できます。選ぶと、その音声はワークスペースに保存され、その市場向けのすべての読み上げで再利用されます。メキシコ向けのキャンペーンでは、四半期が変わっても毎回違う声になることなく、同じブランドらしい音声を保てます。

## 公開前にガイドラインに沿って確認してください。

用語は用語集で管理します。その他のすべて（トーン、訴求内容、免責事項、ブランドブックやコンプライアンス文書に記載された市場固有のルール）は、ガイドラインで管理します。

それらのドキュメントを[ガイドライン](/product/guidelines)としてHyperlocaliseにアップロードしてください。Irisはそれらに照らしてクリエイティブ内のコピーをチェックし、違反している具体的なルールを示した指摘を返します。ドキュメントを必須にすると、常に全文が適用されます。その他のドキュメントからは、各チェックに最も関連性の高い箇所が抽出されます。

どのキャンペーンにも適切な確認ステップ：

1. 各市場向けの原文で用語集の用語を確認してください。
2. アセットを翻訳し、ローカライズしてください。
3. 各市場向けのコピーがガイドラインに沿っているか確認してください。
4. 各市場のプレビューでレイアウトと収まりを確認します。
5. 市場に詳しいレビュアーに承認してもらってください。

## 承認を意味あるものにする

承認結果がシステムにフィードバックされることで、一貫性がさらに高まっていきます。

レビュアーが Iris で市場を承認すると、承認済みのコピーがワークスペースメモリに保存されます。次のキャンペーンは、ずれが生じる可能性のある新しい翻訳ではなく、チームがすでに承認したコピーをもとに開始できます。

レビュー担当者が用語の問題を見つけたら、個別のアセットではなく用語集を修正してください。そうすれば、その修正は次のバナー、次の字幕ファイル、次のナレーション、そして製品 UI にもすべて反映されます。

## クリエイティブアセットの一貫性チェックリスト

- [ ] 用語集には、製品名、プラン名、繰り返し使用されるCTA、タグライン、禁止されている表現が含まれています。
- [ ] ナレーションで読み間違えられる可能性のあるブランド名や製品名に、発音を追加しました。
- [ ] 敬体・常体のどちらを使うかは市場ごとに決定し、ガイドラインに記載する。
- [ ] ブランドおよびコンプライアンス関連の文書はガイドラインとしてアップロードされ、必ず従う必要があるものには「必須」と表示されています。
- [ ] 読み上げのたびに使用する、保存済みのブランドボイス、または市場ごとに選択したボイス
- [ ] 承認前に、すべての市場が用語集とガイドラインに照らして確認されている
- [ ] 個々のアセットではなく、用語集で修正する
- [ ] 承認内容を保存し、次のキャンペーンに引き継ぎます

## 始める

製品やウェブサイトですでに Hyperlocalise の用語集を使っている場合、Iris は自動的にそれらを使用します。インポートも、用語ベースの二重管理も不要です。**[Iris をダウンロード](/iris)**して、Mac でキャンペーンのアセットを1つ開き、よく知っている市場向けにローカライズしてみましょう。チームで合意した用語が使われているか、確認してください。
