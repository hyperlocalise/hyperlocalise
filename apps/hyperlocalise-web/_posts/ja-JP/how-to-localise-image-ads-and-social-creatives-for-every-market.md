キャンペーンは月曜日に8つの市場で開始されます。広告コピーは翻訳済みで、キャプションも準備できており、ランディングページも公開されています。

その後、誰かがバナーについて尋ねます。

見出し、オファー、行動喚起のすべてが画像に含まれています。市場ごとに専用のバージョンが必要なため、デザイナーは元ファイルを開き直して翻訳を貼り付けます。ドイツ語の見出しが収まらないことに気づいて文字を小さくし、日本語のフォントがないことに気づき、サイズごと、市場ごとに同じ作業を繰り返します。40点の素材を仕上げた頃には、キャンペーンは木曜日に開始され、ある市場ではまだ前四半期の価格が表示されています。

このガイドでは、画像広告やSNSクリエイティブを適切にローカライズする方法を説明します。作業を始める前に決めておくこと、画像に埋め込まれたコピーの扱い方、公開前に各市場で確認する方法を紹介します。実践編では、多言語アセット向けのHyperlocalise Macアプリ「**[Iris](/iris)**」を使いますが、このチェックリストはどのツールを使う場合にも役立ちます。

## 画像広告がキャンペーンのローカライズで最も難しい理由

製品やウェブサイトのテキストは文字列として存在します。抽出して翻訳し、戻すことができます。画像内のテキストはそうはいきません。

- **画像内のテキストも画像の一部です。** サイズごとにレイヤー付きの元データを保存していない限り、差し替えられるものはありません。
- **市場が増えるたび、作業量も増えます。** 1つのコンセプト × 4サイズ × 8市場で32個の素材になり、コピーを変更するたびに数え直しです。
- **表示領域は固定です。** 英語では収まる見出しでも、ドイツ語では30%長くなることがあり、ボックスのサイズは変わりません。
- **文字体系によって表示のされ方は異なります。**日本語とタイ語は単語間にスペースを入れずに改行します。アラビア語は右から左に読みます。多くのブランドフォントには、これらの文字を表示するグリフがありません。
- **広告にはルールがあります。** オファー条件、価格、免責事項、禁止されている表現は市場ごとに異なり、有料広告でのミスは公になり、大きなコストにつながります。

つまり、本当の課題は翻訳ではありません。デザイン、ブランド用語、法的文言を維持しながら、各市場向けにアセットを作り直すことです。

## ステップ1：言語だけでなく、対象市場を決める

ロケールコードで表記した市場のリストから始めてください： `fr-FR`, `de-DE`, `ja-JP`, `pt-BR`, `ar-AE`.

言語だけでは不十分です。スペインのスペイン語とメキシコのスペイン語では、語彙、口調、丁寧さが異なります。ブラジルとポルトガルのポルトガル語の違いは、多くのチームが想像する以上です。フランスでは、`€49`と表示される価格は`49 €`と表記されます。「ブラックフライデー」のセールは、市場によっては意味が通じなかったり、開催時期を誤解されたりすることがあります。

各市場について、次の内容を書き留めてください：

- **文体。** 丁寧またはくだけた呼びかけ（`tu`/`vous`、`du`/`Sie`）。
- **オファーと価格。** 通貨、形式、そしてオファーが適用されるかどうか。
- **法的文言。**免責事項、利用規約、および規制当局が求めるすべての内容。
- **翻訳するか、書き換えるか。** 語呂合わせや文化的な表現は、翻訳ではなく新しい文章にする必要があるかもしれません。これは[トランスクリエーション](/blog/hyperlocalisation-why-global-growth-needs-more-than-translation)であり、レビューの段階で気づくのではなく、最初に決めておくべきことです。

## ステップ 2：誰かが翻訳する前に用語を整えておきましょう

広告のローカライズでよくあるミスの多くは、文法ではなく用語に関するものです。英語のままにすべき製品名を翻訳してしまう、一般的な機能を競合他社の商標で表現してしまう、法務部門が前四半期に削除した訴求表現が、ある市場で復活してしまう、といったものです。

何かをローカライズする前に、用語集に以下が含まれていることを確認してください：

- **製品名と機能名**、およびそれぞれが翻訳されるかどうか。
- 「無料トライアル」「期間限定」「登録」など、繰り返し使用されるキャンペーン用語の**承認済み訳語**。
- **禁止用語**とは、特定の市場で決して使用してはならない語句を指します。
- **タグライン**は、キャンペーンごとに新たに翻訳するのではなく、市場ごとに承認済みのバージョンを使用します。

Hyperlocaliseでは、Irisはウェブアプリと同じ用語集と翻訳メモリを参照します。承認済みの翻訳が適用され、禁止用語は画面上の文言や画像プロンプトで使えないようにブロックされます。ブランドブックやコンプライアンス文書にルールを記載している場合は、それを[ガイドライン](/product/guidelines)としてアップロードし、文言がルールに沿っているか確認してください。管理責任とルールの徹底については、[各市場でブランドボイスと用語の一貫性を保つ方法](/blog/how-to-keep-brand-voice-and-terminology-consistent-across-markets)で詳しく説明しています。

## ステップ 3：画像内の文言をローカライズする

出発点は2つあり、それぞれ異なるアプローチが必要です。

### 画像が完成しました。

これはよくあるケースです。代理店やデザインツールで作成された、テキストが画像に埋め込まれたフラット化済みのPNGまたはJPEGをお持ちの場合です。

Irisでは、手順は次のとおりです：

1. クリエイティブとして**画像を開く**。
2. **画像内のテキストを読み取ります。** Iris はコピーの各要素を見つけて配置場所を記録するため、見出し、オファー、行動喚起、注意書きをそれぞれ別の項目として取得できます。
3. **該当項目を翻訳してレビュー**し、用語集と翻訳メモリに照らし合わせます。画像ではなくテキストをレビューするので、作業が速く、各市場のレビュアーとも共有しやすくなります。
4. **市場ごとに画像をローカライズします。** Iris が承認済みのテキストを同じ位置・スタイルで描き直し、写真、製品、レイアウトはそのまま維持します。

各結果はその市場向けのクリエイティブとして保存され、元のものの横に表示されるため、市場ごとに比較できます。レイヤー付きファイルやクリーンプレート（背景のみの素材）は必要ありません。

### 一から設計しています。

クリエイティブがまだない場合は、ブリーフをもとにIrisでオリジナルを作成します。ブランドカラー、使用する書体、レイアウト、正確なコピー（引用符で囲んでください）、参考資料としてロゴと商品画像を含めてください。その後、同じ方法でローカライズします。

ローカライズを考慮して原文を作成してください：

- **見出しは短く。** 英語で削った単語は、ドイツ語ではさらに多くの文字数を節約できます。
- **コピーの断片をつなぎ合わせないでください。** 「Save」+「20%」+「today」のように分けると、語順が異なる言語ではうまくいきません。文全体を書いてください。
- **余裕を持たせましょう。** 英語よりも約3分の1多くスペースが必要になることを想定してください。

クリエイティブを多くの市場で頻繁に変更しながら配信する場合は、コピーを画像に埋め込むのではなく、編集可能なテキストレイヤーにすることをご検討ください。テキストレイヤーならいつでも編集でき、ほかのメッセージと同じように翻訳できます。

## ステップ4：各市場でレイアウトを確認する

これはチームが省略しがちなステップで、顧客には気づかれてしまいます。

翻訳すると、文章の長さが変わります。ドイツ語、フィンランド語、フランス語は英語より20～35%ほど長くなることがよくあります。中国語と日本語は短くなるため、空白が不自然に目立つことがあります。アラビア語とヘブライ語は右から左に読むため、左揃えのレイアウトは不自然に見えます。タイ語、日本語、中国語は単語の間にスペースを入れずに改行するため、予想外の位置で行が折り返されます。

すべての市場について、次の点を確認してください：

| 確認項目 | 確認する内容 |
| --- | --- |
| **はみ出し** | テキストの切り詰め、端からのはみ出し、または製品との重なり |
| **改行** | 最終行に単語だけが残る、またはブランド名や価格を途中で分断する改行 |
| **方向** | 右から左に読むテキストを右揃えまたは中央揃えにし、レイアウトのバランスを保つ |
| **フォント** | 文字が欠けて空白の四角で表示される、またはブランドに合わない代替フォントが使われる |
| **数字** | その市場で一般的な表記に合わせた価格、割合、日付 |
| **適切さ** | ソーシャル広告に表示される1秒ほどの間に読める短さのコピー |

Iris はこれらの問題をチェックします。承認前に、各市場向けの表示をフルサイズでプレビューできます。長期にわたるキャンペーンでは、クリエイティブアセットにも同じ考え方を適用し、[ウェブサイトのローカライズ監査](/blog/what-is-a-website-localisation-audit)と同じチェックを実施してください。

## ステップ5：市場に詳しい人と一緒に確認する

AIを使えば、どの市場でも質の高い初稿を作成できます。それでも、費用をかけて顧客に届けるものは、その市場に詳しい人が必ず承認するようにしてください。

レビューを素早く：

- 文脈のない文字列を並べたスプレッドシートではなく、**レビュー担当者には文案とレンダリング済みの画像を送ってください**。
- **具体的な質問をしてください。** 見出しは自然ですか？ オファーは明確ですか？ ブランドイメージに合わない点やリスクはありますか？
- **問題は発生源で修正する。** 用語に誤りがある場合は、個別の画像ではなく用語集を修正してください。そうすれば、以降のすべてのアセットで正しく使用されます。
- **承認内容を保存。**市場で承認されると、ワークスペースに承認済みのコピーが保存されるため、次のキャンペーンはゼロからではなく、その内容をもとに始められます。

## ステップ 6：市場ごとにエクスポートして測定する

承認済みの市場のみをエクスポートしてください。メディアバイヤーがフランス語のバナーをドイツの広告セットにアップロードしないよう、ファイル名にはコンセプト、サイズ、ロケールを含めてください。

そして、ローカライズを測定できるものとして扱いましょう。市場ごとのクリック率とコンバージョンを、翻訳のみの対照群、または前回のキャンペーン結果と比較します。ある市場で成果が振るわなければ、クリエイティブのコピーは、数日ではなく数分で変更できる変数になります。ここで、[市場での実験](/use-cases/market-experimentation)が実用的になります。

## 次のキャンペーンのチェックリスト

- [ ] ロケールコードで市場を一覧表示し、それぞれの文体、オファー、法的文言を含める
- [ ] 見出しとタグラインを翻訳するか書き換えるかを決定する
- [ ] 用語集には、製品名、定期的に使用するキャンペーン用語、使用禁止用語が含まれています。
- [ ] 原文は短く、完全な文で、後から拡張できる余地を持たせて書く
- [ ] 画像内テキストを読み、翻訳し、用語集に照らして確認する】【。
- [ ] すべての市場向けプレビューで、はみ出し、改行、方向、フォント、数字を確認する
- [ ] 各市場に詳しいレビュアーによる承認済み
- [ ] 承認内容を保存し、次のキャンペーンに引き継げます
- [ ] コンセプト、サイズ、ロケール別にファイル名を付け、マーケットごとに結果を追跡する

## 1つのアセットで試す

違いを実感するために、キャンペーンの進め方をすべて変える必要はありません。今月公開するバナーを1つと、これまで後回しにしていた市場を1つ選びましょう。Irisでローカライズして、レイアウトを確認し、仕上がりと所要時間を現在のプロセスと比べてみてください。

Iris は Mac 向けに無料でダウンロードできます。生成には、月額 20 ドルからの有料プランに含まれる AI クレジットを使用します。全体像については[Iris のローンチ記事](/blog/introducing-iris-ai-localisation-engine-for-multilingual-assets)をお読みいただくか、**[Iris をダウンロード](/iris)**して、次のキャンペーンから始めましょう。
