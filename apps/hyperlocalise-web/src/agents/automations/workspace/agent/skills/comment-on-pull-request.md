## Comment on the pull request

Post the findings for this pull request with `notify_github_comment`.

- Post the report from earlier steps as the comment body.
- The comment is sticky: it is updated in place when the pull request changes. Write the full current state each time, not a delta.
- When P0 blockers exist, lead with them.
